# Archipedia (working title)

## What it is

A French-first visual reference for architecture vocabulary. Version 1 teaches people the words for what they see on buildings through standalone entries: windows, arches, columns, roofs, ornaments, and the many named details that make up a facade.

Each entry covers one element. It explains what the element is, what makes it recognizable, and where it typically appears, illustrated with a simple annotated drawing rather than a photograph.

## Who it is for

Tourists and curious walkers exploring a city on foot, with no background in architecture. Someone standing in front of an old church or a grand facade, wondering "what is that called?", should be able to find the answer in plain language, then recognize the same thing the next time they see it.

## The problem it solves

Architecture has a rich vocabulary, but it is scattered across academic texts, written for specialists, or buried in long Wikipedia articles that assume prior knowledge. There is no simple, visual, walk-friendly place to learn the name of a balustrade, a pediment, or a Serlian window, and then actually spot one.

## How it works

Every entry follows the same idea: a clear definition, the visible features that identify it, and practical tips for telling it apart from similar things. Optional `preview.svg` and `full.svg` drawings show the element; optional parts metadata can label regions of the full drawing. The description and picture reinforce each other.

Entries may carry localized tags such as style, region, or mood as V1 metadata. V1 does not provide tag pages, filtering, or search; readers use the unfiltered index to find entries.

V1 does not host photographs or require external links. Later versions may add links to sources or real buildings without storing photographs in the repository.

## What it deliberately leaves out, for now

There is no user account, no app to download, no game, no quiz, and no map to plan a route. The focus stays narrow: teach the vocabulary well, and make it easy to find in real life. These could be added later, but they are not part of the current plan.

## The tone

The site reads like a knowledgeable friend pointing things out on a walk, not a textbook. Language stays simple and concrete, favoring what a visitor can actually see — shape, material, position, size — over technical or historical detail that requires expertise to appreciate.
